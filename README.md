## 🎬 Sobre o Projeto

Uma landing page minimalista e elegante inspirada na identidade visual clássica da **Coca-Cola**. O foco principal deste projeto foi o domínio de posicionamento com **Flexbox** e a criação de uma interface totalmente adaptável para diferentes dispositivos (Desktop, Tablet e Mobile).

> "Things go better with Coca-Cola"

---

## ✨ Destaques do Desenvolvimento

### 📱 Responsividade Total
O layout foi construído com @media queries estratégicas para garantir que o texto e a garrafa se ajustem perfeitamente, mantendo a harmonia visual em qualquer tamanho de tela.

### 🎨 Estética UI/UX
* **Background Dinâmico:** Uso de logo com baixa opacidade (`opacity: 0.15`) para criar profundidade sem poluir o visual.
* **Tipografia:** Uso de fontes sem serifa para um ar moderno e limpo.
* **Componentes Customizados:** Header com menu hambúrguer e Footer estilizado com ícone global.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica.
* **CSS3:** * Flexbox para alinhamento.
    * Posicionamento absoluto/relativo para sobreposição de elementos.
    * Variáveis de cores e transições suaves.
